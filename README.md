# ownsite

A personal website built with plain HTML, CSS and JavaScript. It has no dependencies and no build step.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Edit content

- **Text, projects, skills:** `index.html`
- **Colors and layout:** `styles.css` (colors are variables at the top)
- **Interactions:** `script.js`

## Publish on GitHub Pages

In the repo on GitHub, go to **Settings → Pages**, choose **Deploy from a branch**, pick the branch and the `/ (root)` folder, then save.
